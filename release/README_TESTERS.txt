souldew for Nintendo 3DS - beta {{VERSION}}
============================================

A Nuzlocke tracker for Pokemon X / Y, Omega Ruby / Alpha Sapphire, Sun / Moon and
Ultra Sun / Ultra Moon (your own cartridge or eShop copy).

You need: a 3DS / 2DS with custom firmware, Luma3DS 13 or newer - the newest
(v13.5) is best (check: hold SELECT while turning the console on - the version
is at the top of the Luma3DS configuration screen).

INSTALL FROM THIS ZIP
1. Turn the console off, put the SD card in your computer.
2. Copy the folders "3ds" and "cias" from this zip to the ROOT of the SD card
   (merge them with the folders that are already there).
3. SD card back in, console on. Open FBI > SD > cias > souldew.cia > Install CIA.
   souldew now has its own icon on the HOME menu.
   (No FBI? Start souldew from the Homebrew Launcher instead - same app.)

TURN ON THE PLUGIN LOADER (once)
Press L + D-Pad Down + SELECT (Rosalina menu), select "Plugin Loader: [Disabled]"
and press A so it reads [Enabled], then B to leave. (souldew also offers to switch
it on when you start a game.)

PLAY
Open souldew > New run > pick your game and rules > Start game.
In game: press SELECT (or hold the small tab in the bottom screen's corner) to
open souldew's screens. B or SELECT goes back to the game.

FEEDBACK
souldew Discord, forum #beta-feedback. Please include: console model
(Old/New 3DS/2DS), Luma3DS version, game + version (e.g. "Y, update 1.5"),
cartridge or eShop, what you did, what you expected, what happened.
A photo of the screen helps a lot.

Your runs are stored in sdmc:/souldew/runs.json - keep it when you update.
Full guide: docs/TESTERS.md in the souldew-3ds repository / the Discord post.
